Hayat Crowd

One tap on a Google Maps page tells the office how busy that place is right now.

  1. Copy the code below (tap the box, Select all, Copy).
  2. In Safari / Chrome: bookmark any page, then edit the bookmark — name it Crowd and replace its address with the copied code.
  3. Open a restaurant in Google Maps in the browser (not the app) — for example ours:
    google.com/maps · Hayat Fish and Mandi
  4. Open the bookmark Crowd. It reads the busy bars, asks for a short key once, and saves.

The first time it asks for the robot word from firestore.rules. Until the rules are published, any word works.
