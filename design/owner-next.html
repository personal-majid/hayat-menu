Design review · owner app next · v2

Everything you touch is at the bottom.

Range chips, the nav and every filter sit within a thumb. The top only tells. Live is the home screen: open orders newest first, every table, the pass, the last bills. Colour is time: an order or a table goes green → amber → red as the minutes pass, continuously, not in three steps.

Age colour

Hue runs 120° (green) to 0° (red) over 0–40 min for orders, 0–60 min for a seated table, 0–prep-time×1.5 for a kitchen ticket. Same scale everywhere so one glance reads the room. Lightness is held constant so red never looks "louder" than green.

Range chips

One strip, always visible: Today · Yesterday · Week · Month · Last month · Pick. Today is live; the others show the same screens as totals. Pick opens the calendar heat-map as a bottom sheet.
